# Empire — Delivering Happiness

Website and staff CMS for Empire, a real-estate developer in Uttar Pradesh. The canonical site will be `https://empirebuildcon.com`.

**Start with the developer handbook: [`handbook/README.md`](handbook/README.md).** It covers what the project is, the current status, the repository map, git and review rules, code and comment rules, architecture, decisions, security, the design system and setup.

- Stack: Next.js · FastAPI · PostgreSQL · Cloudinary
- Status: designs done (Phase 2); application code starts in Phase 3
- AI assistants: read [`AGENTS.md`](AGENTS.md)
