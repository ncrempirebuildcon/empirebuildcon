## Goal

The public site is fast on a phone and usable by everyone:
- Lighthouse ≥ 90 on mobile;
- every public route passes axe, has 44 px touch targets and no sideways scroll at 390 px.

The EMI calculator, share buttons and saved homes are task 5.7b (Track B).

## Scope

1. **Speed** (measured first with mobile Lighthouse on the home page, the projects list, a project, a home, the properties list and contact):
   - The Sentry browser SDK (~118 KB gzipped) loaded on every page even with no DSN. It now loads only when a DSN is set, and after the page has loaded (`src/instrumentation-client.ts`).
   - The one stylesheet is inlined (`experimental.inlineCss`), so the first paint doesn't wait for a second request.
   - Fonts go through `next/font/local` (the same self-hosted files). They are preloaded, and the fallback has matched metrics; only the Latin subset loads.
   - Every page gets a description: the last fallback is the site's own line (the SEO audit).
2. **Accessibility and 390 px pass** (`qa/specs/public-pass.spec.ts` found these; all fixed):
   - Footer links, legal links, the header logo, desktop nav and phone links, 404 buttons and breadcrumbs are now 44 px targets.
   - Card titles keep their layout with `-my-2.5 py-2.5`.
   - Checkbox labels (shared `Checkbox`) are 44 px tall without moving the text.
   - "Skip to content" is the first Tab on every page (it sat after the offer banner). Main takes focus, so the next Tab starts inside it.
3. **Budgets in CI:**
   - The old `lhci` job ran on main only, on `/` without the API, so it measured an error page.
   - It is replaced by a Playwright project, "lighthouse", run in its own CI job on every push. It uses the API, a published project and median-of-3 scores, and uploads the reports.
   - `pnpm e2e` names its projects, so it never runs Lighthouse.

**Out of scope:**
- the 5.7b tools;
- image formats beyond what the Cloudinary loader already does (`f_auto`);
- field data (Core Web Vitals from real visitors), which needs analytics after the consent banner (Phase 6).

## Tests required
