## Goal

Every page staff build in the CMS page builder appears on the website, using the resolved blocks from `GET /public/pages/{slug}` (5.1):
- the home page at `/`;
- About, the legal pages and standard pages at `/<slug>`;
- campaign landing pages.

## Scope

1. **Routes:**
   - `/` renders page `home`; `/home` is a 404 (no second copy).
   - `/<slug>` renders any other published page. Unknown, draft and reserved slugs are a 404.
   - `/contact` (5.4) renders the "contact" page's blocks under its forms when that page is published.
2. **All 17 block types**, each a server component, with honest output:
   - **Rendering basics:**
     - formatted text through `FormattedText`;
     - images through `PublicImage` with their honest labels;
     - links only as the API validated them;
     - a hidden or unresolved block is never shown (the API already leaves it out).
   - **`stats`:** every number shows its source and as-of date (D-035).
   - **`video`:**
     - a library video plays from Cloudinary;
     - a YouTube or Vimeo video is a link with the video's title. No third-party embed or script until Phase 6's consent banner (PLAN standing rules).
   - **`lead_form`:**
     - uses the 5.4 form;
     - the API adds the project's slug, name and RERA details, so the form can send the slug and show the RERA block (number, QR, up-rera.in);
     - a site-visit or brochure block with no project falls back to the enquiry form (those leads need a project).
   - **`map`:** uses the 5.3 map, with the project's RERA block.
   - **`project_grid` / `property_grid`:** use the 5.3 cards.
   - **`offer_banner`:**
     - no countdown;
     - the terms line and its link are shown.
3. **Legal pages:**
   - a visible DRAFT notice while the text is still marked draft (`is_draft_text`, D-017);
   - the legal version, if any.
4. **Landing pages:** `noindex` (the API says so). They keep the site shell.
5. **Titles:** `<title>` from the page's SEO title or its title. The rest of the metadata is 5.6.

**Out of scope:**
- metadata beyond `<title>`, structured data and the sitemap (5.6, 5.6b);
- third-party embeds;
- Hindi pages.

## Tests required

- **Unit:**
  - the block switch renders each type from a fixture;
  - unknown types render nothing;
  - stats always show their source;
  - the video link carries no third-party script.
- **Browser:**
  - a page built through the CMS API with one block of every type shows each one on the site;
  - the home page renders its blocks;
  - a legal page shows its DRAFT notice;
  - draft and unknown pages are a 404;
  - a lead-form block sends a lead (counts within the intake budget, or a mocked answer);
  - axe, the enforced CSP and 390 px.
